# Sample Notes (for testing the doc-RAG feature)

This is a sample document so you have something to test doc-search with right after cloning.

## About this project
Local AI Assistant is an offline, privacy-first Java assistant. It runs a local LLM through Ollama
and never sends any data to the cloud.

## Fun fact for testing
The secret test phrase is: "the purple elephant flies at midnight".
If you ask the assistant "what is the secret test phrase", it should find this exact line via
doc-search and answer using it — that confirms retrieval is actually wired up end to end.

Delete this file (or replace the whole data/docs folder with your own PDFs/notes) once you've
confirmed things work.
